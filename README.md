# Bincom Interview

This repository contains my solutions for the Python Trainee assessment. 

### Files Included:
* `main.py`: Questions 1 through 5
* `database.py`: Question 6.
* `search.py`: Question 7
* `generato.py`: Question8
* `fibonacci.py`: Question 9
* `binary_sequence.py`: Exta

### How to Run:
1. Ensure Python 3 is installed.
2. For the database script, install psycopg2: `pip install psycopg2-binary`
3. Update the `db_config` dictionary in `database.py` with your local PostgreSQL password.
4. Run the main python code: `python main.py`
5. Run the database code: `python database.py`
